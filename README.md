# Luminus: Neon City Portfolio

An interactive Three.js portfolio set in a neon city. Explore project buildings, view profile and repository details, and watch the animated traffic, pedestrians, and rain.

Open `index.html` in a browser to run it. Use `WASD` or the arrow keys to move, drag to look around, and `Shift` to sprint. Press `T` for the guided tour, `R` to toggle rain, `P` to toggle pedestrians, and `L` to open the project list.
